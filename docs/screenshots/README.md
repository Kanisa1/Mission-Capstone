# Screenshots Directory

This directory contains screenshots of the Mineral Traceability System application.

## How to Add Screenshots

Save your screenshots with the following names in this directory:

1. **01-onboarding.png** - Welcome/Onboarding screen
2. **02-login.png** - Login screen
3. **03-dashboard.png** - Dashboard with metrics
4. **04-verifications.png** - Verifications list page
5. **05-audit-trail.png** - Audit trail page
6. **06-sites-minerals.png** - Sites & Minerals management
7. **07-users-roles.png** - Users & Roles management
8. **08-api-console.png** - API Console testing interface
9. **09-profile.png** - User profile page

## Screenshot Guidelines

- **Format**: PNG (preferred) or JPG
- **Resolution**: High quality, readable text
- **Naming**: Use the exact filenames listed above
- **Content**: Ensure no sensitive data is visible in screenshots
